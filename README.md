# debug-server

## Overview
`debug-server` is a simple backend server designed for debugging purposes. It logs all incoming requests, capturing every detail about the request, and does nothing else.

## Features
- Logs all incoming requests
- Captures detailed information about each request

## Installation
To install the dependencies, run:
```bash
npm install
```

## Usage
To start the server, run:
```bash
npm start
```

## Configuration
No additional configuration is required. The server will start logging requests as soon as it is running.
